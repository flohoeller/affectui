# Contributing to affectUI

Thanks for helping! A few things to know first.

## How this repository works

The files here are **generated**: every free item is synced from the affectUI source whenever the site is updated. Pull requests against these files would be overwritten by the next sync, so changes go through issues instead.

## Report a bug

[Open a bug report](https://github.com/flohoeller/affectui/issues/new?template=bug_report.yml) with:

- the item (e.g. Reaction Bar) and what you expected
- your setup: React version, framework (Next.js, Vite, …), browser
- a minimal snippet or a screenshot if you can

## Request a component

[Suggest an item](https://github.com/flohoeller/affectui/issues/new?template=component_request.yml). Links to a reference (an app, a Dribbble shot, a video) help a lot.

## Questions

Ask in [Discussions](https://github.com/flohoeller/affectui/discussions) or reach out on [X](https://x.com/flohoeller).
